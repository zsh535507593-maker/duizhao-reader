# 对照 · 双卷阅读

将原件与改件并排打开的 PDF 阅读网站。原生 HTML、CSS 和 JavaScript，使用本地打包的 Mozilla PDF.js 6.5.438。

## 使用

1. 左侧选择原件，右侧选择改件，也可直接拖入文件。
2. 默认连续滚动阅读，左右同步到对应页及页内位置，每侧可独立设置缩放和旋转。
3. 两份文件页码有差异时，先关闭同步，分别翻到对应页，再点“对齐当前页”。
4. 外观提供白昼、暖纸、墨夜。默认保留 PDF 原色。“页面跟随阅读主题”会改变屏幕显示色彩，核对命盘颜色时保持关闭。
5. 可以搜索有文字层的 PDF、选字复制、保存对照页、恢复上次阅读。扫描 PDF 可以阅读，搜索复制需要文件本身已有 OCR 文字层。
6. 手机屏幕用“原件 / 改件”切换。电脑可拖动中缝调整比例，双击中缝恢复等宽。

快捷键 `← / →` 翻页，`F` 专注阅读，`B` 保存当前对照页，`Ctrl+F` 搜索。先点击需要操作的一侧。

## 文件与隐私

用户 PDF 在浏览器中解析，网站没有上传接口。勾选“在本机记住文件、批注与阅读进度”时，PDF 存入当前浏览器的 IndexedDB，设置和页码存入 localStorage。不同网址、浏览器与设备之间不会自动同步。可在“阅读记录”中取消保存或清除。

网站自带的三页繁简试读材料为专门编写的功能示例，不是用户原书内容。没有将此前翻译或校订的书籍包含在网站发布文件中。

同步基于手动确定的页码差及页内滚动比例，不自动判断语义段落。PDF 页数不同时，各自停在页码范围内。全书页面连续排列，仅为可见区域附近的页面保留画布和文字层，远处页面释放画布。支持不同尺寸与旋转页面。搜索时逐页读取文字。

## 本地启动

直接双击项目中的 `启动阅读器.cmd`。需要本机已有 Node.js，启动后会打开 `http://127.0.0.1:8787/`。PDF 解析组件已经放在 dist 中，本地使用不需要外部 CDN。

开发命令 `npm ci`、`npm run build`、`npm test`、`npm run preview`。不直接双击 dist/index.html，模块与 PDF worker 需要通过 HTTP 服务加载。

## 验证

核心测试覆盖页码偏移、边界、非数字输入、页面适宽和整页计算、滚动比例、中文搜索切片、PDF 文件头识别。

浏览器已实测三页中文 PDF 的显示、两侧页码偏移同步、文字层、中文搜索、三套主题、页面色彩开关、手机布局和刷新后恢复。浏览器扩展的本地文件代选权限未开启，系统窗口自动授权也未完成，因此自动文件选择全流程没有通过代操作验证。普通用户手动选择文件不依赖此扩展权限。

PDF.js 使用 Apache-2.0 许可，许可文件保留在 dist/vendor/LICENSE。

## 连续阅读与批注（2026-11-13）

“批注工具”可展开或收起：阅读、荧光框选、画笔、文字、批注、修订、选择、橡皮。阅读模式下选择文字可直接加荧光。扫描件也支持框选与涂画。点击原件或改件可切换操作侧。选择已有批注可修改文字、字号、颜色或删除；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。

右上“导出 PDF”可分别导出原件、改件。保留原页面及文字层，将新增内容以矢量绘图和嵌入字体写入页面，并保留阅读器内设置的旋转。标记在导出文件中固定；网站内按原 PDF 指纹存储可编辑的批注，重新打开原件可继续修改。没有上传接口。

文字修订是白底覆盖后添加文字，不直接重排 PDF 内部文字对象，不移除底层文本，也不能作为敏感信息脱敏。加密文件可以阅读，但导出前需另存为无密码文件。页面主题只影响屏幕显示，不更改导出的原书配色。

依赖 pdf-lib 1.17.1 / fontkit 1.1.1；中文字体为 SIL OFL 的 Noto Sans SC 常规静态实例，许可证与来源见 dist/fonts。导出中文时完整嵌入字体，避免已发现的子集字体缺字问题，文件会相应增加体积。

验证命令：npm test；python tests/verify-export.py（需要 PyMuPDF）。后者逐字检查 PDF 光栅结果，避免“可以提取文字但画面为空”的字体问题。
